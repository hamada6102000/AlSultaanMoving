# صور الموقع / Site images

`SeoService` يفحص وجود كل ملف عند الإقلاع، فأي ملف مفقود لا يظهر في الصفحة أصلاً بدل أن يُكتب رابط مكسور.
**أعد تشغيل التطبيق بعد إضافة أي ملف.**

`SeoService` probes for each file at startup, so a missing file is omitted from the markup
rather than emitted as a broken URL. **Restart the app after adding a file.**

الخدمات بدون صورة تُبقي تصميم الأيقونات الحالي عمداً — لا تُوضع صور بديلة أو غير ذات صلة.
لإضافة صورة لخدمة، أضف الحقل `image` لها في `App_Data/content.json`:

```json
"image": { "src": "/img/services/packing.jpg", "alt": "وصف عربي يذكر الخدمة والمدينة", "width": 800, "height": 600 }
```

## عند وصول الشعار الجديد / When the new logo arrives

الملفات التالية مؤقتة، مأخوذة من حزمة «الأمانة» ولا تحمل اسم شركة — تُستبدل كلها بما يقابلها من الحزمة الجديدة:

| استبدل | بماذا |
|---|---|
| `brand-mark.svg` | العلامة المربّعة الجديدة (تظهر 46×46 في الهيدر والفوتر) |
| `icon-512.png` / `icon-192.png` | أيقونة التطبيق الجديدة |
| `../favicon.ico` / `../favicon.svg` / `../apple-touch-icon.png` | أيقونات المتصفح الجديدة |
| `mark-truck.svg` | رمز بدون إطار (أو احذفه إن لم يُستخدم) |

ثم أضف `logo.png` (512×512، شعار كامل باسم الشركة) وحدّث `appsettings.json`:

```json
"LogoPath": "/img/logo.png"
```

ولا تنسَ إعادة تشغيل التطبيق. المسارات كلها مقروءة من الإعدادات، فلا حاجة لتعديل أي كود.

## قواعد / Rules

- **لا صور تحمل علامة حساب آخر.** أربع صور من الدفعة الأصلية تحمل علامات
  `@naql_dammam` و`@alsalemaldela` ولم تُستخدم — هي محتوى شركات أخرى.
- **لا صور ستوك.** إن لم توجد صورة حقيقية مناسبة، يبقى تصميم الأيقونات.
- كل صورة تحتاج `alt` عربي وصفي يذكر الخدمة والمدينة.
- كل صورة تحتاج `width` و`height` صريحين لتفادي قفز التخطيط (CLS).
- صور المدونة القديمة (47 صورة من ووردبريس) كانت محذوفة من الخادم وتُرجع 404، فأُزيلت مع أكواد `[caption]` المرافقة لها.
